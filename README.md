## Requisitos previos

- Node.js (versión 18 o superior)
- npm (incluido con Node.js)

## Estructura del código

- `src/App.jsx`: Componente principal de React con la interfaz de videos, artículos.
- `src/index.css`: Directivas de Tailwind CSS e indicadores de foco accesible.
- `src/main.jsx`: Punto de entrada de la aplicación React.
